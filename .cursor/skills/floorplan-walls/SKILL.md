# 户型认墙

只临摹画出来的墙。不要设计房间。思考用简体中文。

运行时提示词：`src/vision/ai-walls-prompt.ts`（含技能包）。
结果经 `applyWallTraceToModel` 入库。禁止编造 `model_url`。
每次认墙会把原始 JSON / findings / 核对意见写到 `tmp/ai-detect/`（`latest.json` 是最近一次）。

## 规则

1. OCR 文字只用于比例和房间名。数字不是墙。尺寸界线、开间/进深细线和两端短刻度不是墙。
2. 图层关不掉时先在脑子里裁图：丢掉 AutoCAD/软件界面、Teams 窗口、图签图框、尺寸界线、轴线、图例。只认建筑本体。
3. CAD 墙是双线：`outerLoop` / `innerWalls` 只输出中心线，禁止描内外两皮。
4. `outerLoop` 从真实墙角起笔，顺时针一圈。含阳台外沿和每一个凹凸拐角（左侧台阶：次卫凸出、空调位、入口退线）。禁止从墙中点起笔，禁止画成一条光秃竖线，禁止 4～6 个点的示意矩形/L。
5. `imageWidth`/`imageHeight` 必须用附图真实像素，禁止编造 1920×1200。坐标对着墙线数，不要先估一个框。
6. 每个坐标必须在图像内，且落在建筑本体上，不要点到图签或工具栏。
7. `innerWalls` 必须从墙接到墙（或门垛），每个有名字的房间四壁都要接到。门洞只空约一扇门宽（40～70 像素），门弧写入 `findings.openings`，不要把门连成实墙，不要整面隔墙不画，不要写几十像素的短棍。
   外墙之后最优先描**粗承重墙**（白底粗黑双线 / CAD 粗白双线）。带拐弯、错台、凹凸的必须按拐角落点拆段，禁止拉成一条直线。
   L 形粗墙两肢都要画（书房/客厅厚墙的短横回头不能省）。主卫左右承重墙、封口墙和门，厨房四壁，左侧次卫/入户墙和门，都不能漏。
8. 衣帽间只画房间四壁；柜内 X 填充、层板、橱柜、岛台、洁具不是墙。
9. 柜体/家具看不清就省略。看得见的房间隔墙必须画。不要为了封闭房间而凭空补墙，不要对称抄墙。
10. 后处理不能拆外墙闭合圈。墨迹约束只过滤隔墙；隔墙丢掉一半以上时不要用过滤结果。本地补线只加粗墨线（双线/承重）且必须接到已有墙端或形成 L 短回头；禁止用细标注线闭圈。模型坐标与图像尺寸不一致时要按比例缩放，不能只改宽高。
   墙体可导出/导入 draw.io XML（`savedFloorplanToDrawio`）。
11. 认墙和摆家具分开：先只落墙，用户确认后再生成家具和门窗。
12. 导入底图只换图，绝不自动认墙。进行中的认墙要中止，并恢复认墙前的墙体。重新认墙需确认。

## 模型

认几何用文档视觉模型（`gemini-3.1-pro`），不要用默认写代码模型。
